# Joe Hahn

**Senior Drupal & web developer.** 20+ years building, migrating, and maintaining sites for
universities, nonprofits, and businesses.

Drupal is my specialty — I've carried sites through every major version from **Drupal 6 to 11**,
built custom themes and editorial workflows, and rescued more than one inherited or failing
codebase. A lot of my best work is the untangling kind: stepping into an existing site, figuring
out how it's actually put together, fixing what's broken, and making changes safely without
breaking what already works.
